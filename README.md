Nox Browser — это современный, быстрый и кастомизируемый браузер, построенный на базе движка Gecko (форк Firefox). Наша цель — дать пользователям полный контроль над внешним видом и поведением их проводника в интернете.

## ✨ Особенности

*   **Полная кастомизация UI:** Изменяй темы, расположение элементов и анимации с помощью CSS.
*   **Гибкое поведение:** Настраивай горячие клавиши, поведение вкладок и логику интерфейса через JS.
*   **Приватность:** Мы берем лучшее от движка Gecko, отключая лишний телеметрию.
*   **Собственная сборка:** Nox Browser поставляется с уникальным дизайном "из коробки".
